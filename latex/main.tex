\begin{abstract}
We test whether movie overviews improve prediction of recorded box-office
revenue beyond release timing, genre, runtime, franchise membership, and
production company. We use nonnegative matrix factorization to describe five
topics in 32,105 English-original-language overviews. For prediction, we compare
three text representations in ridge regressions across four chronological
evaluation windows covering 2,660 films. The metadata model has a pooled mean
absolute error of 1.666 in log revenue units. Adding a frozen sentence embedding
increases error by 0.025 (95\% paired interval 0.005 to 0.045), while removing
production-company indicators increases it by 0.166 (0.127 to 0.204). TF--IDF
increases error and topic weights make little difference. The overviews yield
interpretable themes, but the tested text representations show little incremental
predictive value given the available metadata.
\end{abstract}
